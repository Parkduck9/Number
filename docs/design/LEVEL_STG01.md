## 0. 기준 수치 (설계에 쓴 값)

| 항목 | 값 | 출처 |
|---|---|---|

| 재추첨 가중치 | 초반 {2:40, 3:40, 4:15, 5:5} ~ 후반 {2:5, 3:15, 4:40, 5:40}, `progress`로 보간 | ARCH 4절, Q-C `[확정]` |

**발판 높이 규칙** `[제안]` — 모든 구간 공통. 한 단 높이 1.5u (최대 점프 2.5u보다 1u 여유, 짧게 눌러도 올라감).

| 층 | 윗면 y (유닛) | 그림 기준 (위에서부터 px, 540px 높이) | 무엇 |
|---|---|---|---|
| 바닥 G | **2.0** | 476 | 저잣거리 돌길 |
| 1단 | 3.5 | 428 | 상자·좌판·계단 끝 단 |
| 2단 | 5.0 | 380 | 노점 차양 |
| 3단 | 6.5 | 332 | 한옥 낮은 지붕 용마루·담장 위 |
| (사용 안 함) | 8.0 이상 | 284 이하 | 배경 전용. 이보다 높은 지붕은 밟지 않는다 |

- 바닥(2.0)에서 차양(5.0)은 3u라 바로 못 올라간다 → **반드시 상자를 밟고 올라가게** 해서 점프 단계를 가르친다.
- 발판 위 캐릭터 머리 + 숫자 라벨(머리 위 1.6u)이 6.5 + 2 + 1.6 ≈ 10.1u. 화면 위쪽 HUD(얼굴 초상화)와 겹치지 않는다.
- 배경 높이 = 화면 높이(540px)이므로 **카메라 y는 8.4375로 고정**, 가로로만 따라간다. 카메라 x는 [15, 전체길이 − 15]로 제한. `[제안]`
- 떨어져 죽는 구덩이는 없다. 지붕에서 떨어지면 거리 바닥에 내려선다. `[제안]`

## 2. 구간별 설계

### SEG-A — 장터 입구

**그림 (14번 기준)**: 왼쪽·오른쪽 끝에 같은 모양의 붉은 대문, 가운데 노점 4채(분홍·청록 차양), 뒤로 한옥 지붕과 고층 건물. 바닥은 평평한 돌길 하나. 이 구간에서는 전광판을 **꺼진 검은 화면**으로 그린다 (켜지는 건 SEG-C). `[제안]`

**걸을 수 있는 곳**
- 바닥 x 0~50.625, 윗면 2.0
- 상자 C-A1 x 26~28, 윗면 3.5 (길을 막음 → 첫 점프)
- 차양 AW-A1 x 27.5~32, 윗면 5.0 (선택 경로, 단방향 발판)

**흐름**
1. x 3 시작 (CP-A0 = 게임 시작 지점, GDD 5장 `[확정]` 첫 체크포인트).
2. x 6 짧은 대사 트리거 (LINE 미작성, `[제안]`): 유도가 얼굴 앞 숫자를 띄운 시민들을 처음 본다.
3. **E-A1** x 20, **숫자 2 고정** `[제안]`. 혼자, 평지, 양옆 10u 이상 비어 있음.
   - 배우는 것: 숫자 = 연속 공격 횟수. 2번 막거나(패링) 피하면(대시) 반격 창 1초. 체인 중 정면 공격은 튕김 `[확정]`. 3타면 쓰러짐 `[확정]`.
4. 상자 C-A1을 넘는다 (높이 1.5, 짧은 점프). 차양으로 올라가 봐도 되고 지나쳐도 된다 → SEG-B의 오르기 예습.
5. **E-A2** x 44, **숫자 3 고정** `[제안]`. 플레이어 뒤(x 32~40)에 8u 이상 빈 평지.
   - 배우는 것: **돌격(Charge)** `[확정]`. 뒤로 물러나 사거리를 벗어나면 적이 돌진해 온다 → 물러나지 말고 그 자리에서 패링. 처음 당해도 체력 5라 버틸 수 있다.
   - 화면 힌트 한 줄 `[제안]`: "Back off and it charges. / 물러나면 돌진한다." (돌격을 처음 당한 뒤 한 번만)
6. x 47~50.6 오른쪽 대문 → SEG-B.

### SEG-B — 지붕 골목

**그림 (13번 왼쪽·가운데 기준)**: 노점과 좌판, 그 뒤 돌담, 담 위로 길게 이어지는 한옥 지붕. 13번에서 주인공이 달리는 그 지붕 라인을 3단(6.5)에 맞춰 다시 그린다. 구간 오른쪽에 **거리를 막는 높은 돌담**을 둔다 — 지붕으로만 넘어간다.

**걸을 수 있는 곳**
- 바닥 x 0~50.625, 윗면 2.0
- 상자 C-B1 x 25~27, 윗면 3.5
- 차양 AW-B1 x 26.5~30.5, 윗면 5.0 (단방향)
- 지붕 R-B1 x 29.5~46, 윗면 6.5 (단방향, 16.5u — 지붕 위 싸움에 충분)
- 돌담 W-B1 x 43~46, y 2.0~6.5 (단단한 벽, 4.5u라 못 넘음 → 지붕 경로 강제)

**흐름**
1. x 3 CP-B0 `[제안]`.
2. **E-B1 x 16, E-B2 x 19** — 첫 2명. 숫자 재추첨 (progress 0.3, 대부분 2~3) `[확정]` 규칙.
   - 배우는 것: 두 숫자를 동시에 읽고, 한 명을 등지면 등 뒤 공격은 패링이 안 된다(Q-I `[확정]`). 대시로 둘 사이를 빠져나가 한쪽으로 몰기.
   - 싸움 공간 x 5~24 평지.
3. 상자(3.5) → 차양(5.0) → 지붕(6.5) 오르기. 단마다 1.5u.
4. **E-B3** x 40, 지붕 R-B1 위. 재추첨 (progress 0.3).
   - 배우는 것: 좁은 곳(지붕 끝)에서 돌격을 당하면 떨어진다 — 떨어져도 바닥으로 내려갈 뿐이고 다시 올라와야 한다. 대시로 등 뒤로 넘어가기(Turn 0.35초 `[확정]`)를 쓰기 좋은 너비.
   - **적이 지붕 끝에서 멈춰야 한다** (현재 TestEnemy는 가장자리 개념 없음) → 열린 질문 Q2.
5. 지붕 끝 x 46에서 거리로 내려간다 → x 50.6 기둥(이음새) → SEG-C.

### SEG-C — 전광판 광장 → 거리 끝 문

**그림**: 왼쪽·가운데는 넓은 광장, 뒤쪽 중간층에 **14번의 큰 전광판** (x 약 14~30, y 약 10~15). 오른쪽 끝은 **13번의 대문과 돌계단** — 스테이지 목표 "거리 끝".

**걸을 수 있는 곳**
- 바닥 x 0~40, 윗면 2.0
- 계단 경사 ST-C1 (40, 2.0) → (45, 4.0) (약 22°)
- 대문 앞 단 x 45~50.625, 윗면 4.0

**흐름**
1. x 3 CP-C0 `[제안]`.
2. x 7 **방송 트리거**: 전광판이 켜지며 "3", 짧은 차임(SFX-01). 이 순간부터 SEG-C 적 전원 숫자 3, 재추첨해도 3. NUM-3 `[제안]`.
   - 대사 한 줄 `[제안]`: "Three. Everyone swings three times now. / 3이다. 이제 다들 세 번씩 휘두른다."
3. **E-C1 x 20, E-C2 x 23** (둘 다 3). 2명이지만 숫자가 같아 세기 쉽다 — 앞 구간보다 어렵지 않게, "방송 숫자가 모두를 바꾼다"를 보여 주는 자리.
4. **E-C3** x 34 (3). 뒤쪽 x 24~32 빈 평지 → 돌격 복습.
5. 계단을 올라 대문 x 48 **목표 트리거** → 스테이지 클리어 → STG-02 (기와지붕 고가 철로).

- 체크포인트 3곳(각 구간 시작). 체크포인트 체력 회복은 GDD `[제안]` 그대로.

### 5.3 지금 코드에 없어서 필요한 것 (모두 `[제안]`, 구현 전 사용자 확인)

1. **적 활성 거리**: 지금 TestEnemy는 항상 플레이어에게 걸어온다 → 씬에 8명을 두면 모두 몰려온다. 제안: 플레이어가 수평 10u 안에 오고 \|dy\| ≤ 1.5일 때 활성화.

4. **단방향 발판**: PlatformEffector2D (아래에서 뚫고 올라감). 아래로 내려가기 입력은 없음 — 끝에서 걸어 내려간다.
5. **경사 위 미끄러짐**: 계단 경사에서 서 있으면 미끄러질 수 있음 → 마찰 있는 물리 재질, 또는 계단을 1.0u 단 2개로 바꾼다.
6. 구간 progress 값(0 / 0.3 / 방송), 체크포인트·목표 트리거, 카메라 고정 y.

## 6. Play 모드 확인 항목 (빌드 후)

- 시작해서 바로 오른쪽으로 걸으면 x 10 근처에서 E-A1(숫자 2)만 다가온다. 다른 적은 움직이지 않는다.
- 상자 C-A1은 짧게 눌러도 넘을 수 있고, 차양 AW-A1은 상자 위에서만 올라간다 (바닥에서 바로는 안 됨).
- SEG-B 돌담 W-B1은 바닥에서 넘을 수 없고, 지붕 R-B1로만 지나간다.
- E-B3는 지붕 끝에서 떨어지지 않는다.
- SEG-C 트리거를 지나면 전광판이 켜지고 E-C1~C3의 숫자가 모두 3, 반격 뒤에도 3.
- 화면 위아래로 카메라가 흔들리지 않고, 배경 바닥선과 콜라이더 윗면이 픽셀 단위로 맞는다.
- 처음부터 끝까지 막힘 없이 약 2~3분.
