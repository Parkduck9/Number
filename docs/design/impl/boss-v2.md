# 최종 보스 v2 — 합체 배경 보스 (STG-05)

> 2026-11-10. 근거: [DECISIONS.md](../DECISIONS.md) 23. 컨셉: [concept/boss/boss_concept_4.png](../concept/boss/boss_concept_4.png) (몸·배치), 얼굴은 빼고 숫자만.
> 이전 보스(전광판 + 잡몹 3웨이브, [boss.md](boss.md))를 대체한다.
> `[확정]` = 사용자 결정, `[제안]` = Claude 제안(확인 전 구현 안 함), (T) = 플레이 후 조정.

## 1. 한눈에
- `[확정]` AI 벌레 + 안드로이드 + 강한 적이 뭉친 **거대한 합체 기계**. 경기장 **뒤 배경 전체**를 채우고, 공격하는 부위만 앞으로 뻗어 나온다.
- `[확정]` **얼굴은 없다.** 가운데 큰 홀로그램 창에 **숫자만** 뜬다 (다른 적과 같은 규칙). 순박한 척하는 얼굴은 쓰지 않는다.
- `[확정]` 부위마다 자기 기믹에 맞는 공격 **3가지**:
  - **왼팔 = 벌레 팔** (죽은 AI 벌레 껍데기가 뭉친 팔) → 벌레 떼
  - **오른팔 = 강한 적의 팔** (빨강·금 갑옷, 곧은 칼) → 내려치기 + 맞부딪힘 대결
  - **가슴 = 총·미사일 해치** (갈비뼈 같은 해치) → 탄막
- `[확정]` 더 무섭게: 거대하고 어두운 몸, 혈관 같은 케이블, 어둠 속 빨간 눈빛. **피 표현 없음** — 컨셉의 빨간 얼룩은 검은 기름·청록 냉각액으로 바꾼다 (JAM_RULES 안전).

## 2. 예고 규칙 — 숫자가 공격을 예고한다
- 홀로그램에 **다음 공격 아이콘 + 숫자 N**이 뜬다. 아이콘: 벌레 / 칼 / 조준점.
- N = 그 공격의 **연속 횟수** (게임 핵심 규칙 그대로). 숫자는 공격 중에 줄지 않는다.
- 아이콘이 뜬 뒤 1.0초 (T) 동안 해당 부위가 빛나며 준비 → 공격.

## 3. 공격 3가지

| | 아이콘 | 예고 | 공격 | 피하는 법 | 보스가 다치는 순간 |
|---|---|---|---|---|---|
| **A 벌레 떼** | 벌레 | 왼팔 손바닥이 열림, 붉은 빛 | 벌레 떼가 경기장을 가로로 휩쓰는 **파도 N번**. 파도마다 높이가 다르고 **빈틈**이 하나 있다 | 빈틈으로 점프·대시, 부적 던지기로 위로 이동 | 파도가 지나간 뒤 팔이 1.5초 (T) 바닥에 늘어짐 → 팔을 때리면 피해 |
| **B 칼팔** | 칼 | 바닥에 빨간 위험 구역 | 칼팔이 다리 위로 **N번 내려침** (마지막 한 번은 다리에 박힘) | 위험 구역 밖으로 이동, 대시 | 박힌 팔에 다가가면 **맞부딪힘 대결** (DECISIONS 20, N합). 다 막으면 팔에 큰 피해 |
| **C 탄막** | 조준점 | 가슴 해치가 열리고 노란 경고선 | 황금 미사일·총탄 **N발** 연속 | 탄을 **패링하면 해치로 되돌아가** 피해 | 되돌린 탄이 해치에 맞을 때 |

- 패링 동그라미(근접 예고 링)는 B의 내려치기에도 쓴다.
- 주사위(Space)는 보스전에서 계속 막는다 (DECISIONS 18).

## 4. 단계 (T)
| 단계 | 체력 | 쓰는 공격 | 변화 |
|---|---|---|---|
| 1 | 100~67% | A, B 번갈아 | N = 3~4 |
| 2 | 66~34% | A, B, C 무작위 | N = 4~6, 예고 1.0 → 0.8초 |
| 3 | 33~0% | 두 공격 겹침 (예: C 탄막 중 B 위험 구역) | N = 5~7, 홀로그램이 지직거림 |

- 체력은 숫자로 보이지 않는다 (몸이 갈라지고 부품이 떨어지는 단계 그림으로만).

## 5. 끝 → 엔딩 (DECISIONS 21)
- 체력이 0이 되면 홀로그램 숫자가 깨지고 몸이 멈춘다.
- `[제안]` 그다음 **유도가 남은 기계 설비를 직접 때려 부순다**: 좌클릭할 때마다 서버 랙·화면·케이블이 하나씩 부서짐 (5~7번), 마지막에 전체가 무너지며 화면이 하얘짐 → 엔딩 대사 → 타이틀. 정지 버튼·엔딩 선택창은 없앤다.

## 6. 방송 해킹과의 연결 `[제안]`
- 보스 방에서도 전광판 해킹이 된다면: 해킹으로 **보스의 다음 숫자를 낮출 수 있다** (예: 6 → 2). 행운의 숫자를 내가 정한다는 테마와 맞는다. 보스는 몇 초 뒤 숫자를 되돌린다.
- 구현이 빠듯하면 뺀다.
