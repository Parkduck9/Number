# 강력한 적 — 맞부딪힘 대결 (Elite Clash Duel)

> 2026-11-10 사용자 결정 ([DECISIONS.md](../DECISIONS.md) 20). (T) = 플레이해 보고 조정할 수치.
> 조사 근거: 연속 패링·자세 붕괴형 결투, 박자 패링, 픽셀 카메라 확대 관례 (아래 "참고").

## 1. 한 줄 요약
강력한 적이 공격하면 화면이 확대되고, **머리 숫자만큼 서로 칼을 부딪친다**. 유도가 전부 막아 내면 적을 **부순다**.

## 2. 흐름

| 단계 | 시간 | 일어나는 일 |
|---|---|---|
| 시작 | 0.25초 | 엘리트가 공격 자세(사거리 약 2.5칸, 같은 높이) → 카메라가 두 캐릭터 가운데로 이동하며 **1.5배로 한 번에 확대**(PPU 32→48) + 흰 번쩍임 0.06초 + 위아래 검은 띠(화면 8%) 0.2초. 다른 적·탄·스포너 정지 |
| 교환 ×N | 표 참고 | ① 엘리트가 친다 — 기존 **패링 동그라미**로 타이밍 표시 → 유도 좌클릭 패링, **땅** ② 반 박자 뒤 유도가 자동으로 받아친다 → 엘리트가 막는다, **땅** |
| 부수기 | 약 1.2초 | 마지막 패링 후 0.15초 멈춤 → 0.4초 느리게 → 유도가 돌진 일격 → 엘리트가 4×4 조각으로 깨져 흩어짐, 숫자도 깨짐 → 4px 흔들림 → 0.3초 유지 후 0.35초 동안 카메라·띠 복귀 |
| 실패 | — | 패링을 놓치면 그 공격을 맞는다(평소 피해). 대결 즉시 끝, 카메라·띠 복귀. 엘리트는 숫자 그대로 평소 행동, 다음 공격 때 다시 대결 |

- 대결 중 유도는 이동하지 않고 **좌클릭(패링)만** 받는다.
- 숫자 범위 3~9. **숫자는 바뀌지 않는다.**

## 3. 타이밍 (T)

| 숫자 N | 엘리트 공격 간격 | 대결 길이 (약) |
|---|---|---|
| 3 | 0.80초 | 3.0초 |
| 4 | 0.75초 | 3.5초 |
| 5 | 0.70초 | 4.0초 |
| 6 | 0.65초 | 4.4초 |
| 7 | 0.60초 | 4.8초 |
| 8 | 0.56초 | 5.1초 |
| 9 | 0.52초 | 5.4초 |

- 첫 공격은 대결 시작 0.9초 뒤. 간격은 일정하게 (숫자를 세며 따라갈 수 있게). 0.5초보다 짧게 하지 않는다 (WebGL 입력 지연).
- 패링 판정: 맞는 순간 기준 앞 0.25초 ~ 뒤 0.1초. 공격이 없을 때 누르면 0.25초 동안 패링 불가 (연타 방지).
- 유도의 받아치기 땅은 두 엘리트 공격의 한가운데.

## 4. 진행 표시 — 숫자는 그대로
- 엘리트 발밑에 작은 칸 N개. 패링 성공마다 하나씩 부적 노랑(#F2C94C)으로 켜지고 1프레임 흰 팝.
- 땅 소리는 교환마다 반음씩 높아진다. 마지막 땅이 가장 높다.

## 5. 이펙트 (FX — Claude 제작, 코드로 그림)
| FX | 내용 |
|---|---|
| 패링 땅 | 고른 PARRY 이펙트 시안(A 칼날·B 부적·C 청록 중 하나)을 그대로 쓴다. 유도 쪽 땅과 엘리트 쪽 땅은 좌우 반전 |
| 확대 번쩍임 | 0.06초 흰 화면 |
| 검은 띠 | 화면 위아래 8%, 0.2초 미끄러져 들어오고 나감 |
| 진행 칸 | 4~6px 픽셀 사각형 N개 |
| 부수기 | 엘리트 현재 스프라이트를 4×4로 잘라 사방으로 튐, 중력, **회전 없음**(픽셀 유지), 계단식 투명도로 0.7초 사라짐. 숫자 글자도 조각 2~3개로 깨짐 |

## 6. 엘리트 유닛
- 일반 공격·숫자 규칙은 안드로이드와 같은 계열. 대결 밖에서도 때릴 수는 있지만 체력이 높아(약 6대) 대결로 부수는 것이 정석.
- 그림: Codex 크레딧이 돌아올 때까지 안드로이드를 1.25배·다른 색으로 임시 사용. 크레딧이 돌아오면 전용 스프라이트를 Gemini 컨셉 → Codex로 그린다.
- 처음 배치: STG-02 후반 1명 (테스트용). 보스전·주사위 굴림과 겹치지 않는다.

## 7. 구현 메모
- 하나의 대결 진행기(`EliteDuel`)가 실제 시간 시계 하나로 공격·동그라미·소리·카메라를 모두 맞춘다 (화면과 판정이 어긋나지 않게).
- 다른 적 정지는 주사위와 같은 `GameFlow.EnemiesHeld`를 재사용, 엘리트만 예외.
- 카메라는 `CameraFollow2D`에 "두 대상 가운데 보기 + PPU 한 단계" 추가. 시네머신은 쓰지 않는다 (Pixel Perfect Camera와 충돌).
- 부수기 처치는 평소 처치 경로를 거쳐 스테이지 클리어·주사위 충전이 그대로 동작.

## 8. 참고 (조사 요약)
- 연속 패링으로 자세를 무너뜨린 뒤 마무리하는 결투 구조, 0.2초 안팎의 패링 창, 연타 벌칙.
- 박자 패링: 공격이 일정한 박자로 들어와 귀로도 막을 수 있고, 실패 원인이 분명하다.
- 픽셀 게임의 확대는 부드러운 줌 대신 정수 배율로 한 번에 + 번쩍임으로 끊김을 가린다 (Unity Pixel Perfect Camera 문서).
