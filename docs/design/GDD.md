# GDD — NUMBER

> 이 문서는 사람과 AI(Claude, Codex, Antigravity)가 함께 읽고 고치는 기획서다.
> 구현·에셋·QA 작업은 모두 이 문서의 ID를 기준으로 한다.

## 0. 작성 규칙 (먼저 읽기)

**상태 태그** — 모든 항목 앞에 붙인다. AI는 `[확정]`만 구현 근거로 쓴다.
| 태그 | 뜻 |
|---|---|
| `[확정]` | 결정됨. 바꾸려면 사용자 확인 + 변경 기록 필수 |
| `[제안]` | AI나 팀원이 제안함. 사용자 확인 전까지 구현하지 않음 |
| `[미정]` | 아직 정하지 않음. `TODO(사용자)` 질문과 짝을 이룬다 |
| `[보류]` | 범위 밖으로 미룸. 시간이 남으면 다시 본다 |

**ID 규칙** — 다른 문서·커밋·버그 리포트에서 이 ID로 가리킨다. 한 번 붙인 ID는 지우지 말고 `[보류]`로 바꾼다.
- `NUM-x` 숫자 규칙 (x = 숫자) · `STG-xx` 스테이지 · `CHR-xx` 등장인물 · `LINE-xx` 대사
- `END-xx` 엔딩 · `TASK-xx` 작업 · `Q-xx` 열린 질문 · `ART-xx` 아트 · `SFX-xx` 사운드

**쓰는 법**
- 한 줄에 한 사실. 긴 설명은 표나 목록으로.
- 수치는 단위를 붙인다 (초, 회, px, %).
- 내용은 내용 칸에, 상태 칸에는 태그만 쓴다.
- 모르면 비워두지 말고 `[미정] TODO(사용자): 질문` 으로 남긴다.
- 고칠 때마다 맨 아래 **변경 기록**에 한 줄 추가.

## 3. 세계관

- `[확정]` 조선풍 사이버펑크 도시. 곳곳의 전광판에 행운의 숫자 광고가 나오고, 사람마다 가진 홀로그램이 '오늘의/지금의 행운의 숫자'를 끊임없이 띄운다.
- `[확정]` 여러 사업을 하던 대기업이 AI 고도화로 도시 깊숙이 침투했다 — 정보 수집용 AI 벌레, 공장 자동화, 안드로이드(가정·공업·전투), 자율주행.
- `[확정]` 회사의 AI는 사람들을 쉽게 움직이려고, 눈치채지 못하게 뇌파와 행운의 숫자를 보낸다. 그리고 AI 벌레·안드로이드·공장을 동원해 **숫자가 실제로 행운을 가져다주게 만든다.** 진짜로 맞으니 사람들은 믿게 되고, 점점 세뇌된다.
- `[확정]` 시민 대부분은 숫자를 문자 그대로 맹신한다.
- `[확정]` 소수의 거부자가 있고, 이후 레지스탕스 **'러다이트(Luddite)'**로 발전한다.
- `[확정]` AI를 만든 사람들은 혹시 모를 사태에 대비해 **AI 정지 버튼**을 만들어 두었다. AI는 이 버튼에 사람이 다가오지 못하게 막는다. 게임의 최종 목표.
- `[확정]` 패션: 한복과 현대 옷을 섞어 입는 것이 이 도시의 유행이다 (갓 + 테크웨어, 두루마기 롱코트 + 스니커즈 등).
- `[확정]` 회사 이름: **Embector** (embedded + vector). 행운과 무관해 보이는 차가운 기술 회사 이름이 정체를 숨긴다.
  - 주의: 실존 상장사 **embecta**(인슐린 주사 바늘 제조)와 철자가 비슷하다. 실존 회사를 겨냥한 것처럼 보이지 않게 16장 안전 체크의 회사 관련 항목을 지킨다.
  - 구현: 게임 안의 회사 이름은 설정 값 한 곳에서만 불러온다 (나중에 바꾸기 쉽게).

**해킹 규칙 — 숫자 줄다리기**
- `[확정]` 해킹 UI는 **다이얼**. 숫자를 돌려 고른다 (컨셉 이미지 3번 참고).
- `[확정]` 유도가 숫자를 바꾸면(예: 0) Embector AI가 곧바로 **역해킹**을 시작한다. 바뀐 숫자는 AI의 역해킹이 끝날 때까지만 유지된다.
- `[제안]` 화면 위 방송 숫자 옆에 AI 역해킹 진행 바가 차오른다. 다 차면 AI가 숫자를 되찾는다.
- `[제안]` 유지 시간 기본 8초. 숫자마다 다르게 할 수 있다 (0은 강력하니 짧게, 예: 5초).
- `[제안]` AI가 숫자를 되찾으면 원래 숫자보다 불리한 숫자를 방송한다 (AI가 화가 난 듯 7 도핑 등).
- `[제안]` 0이 유지되는 동안 사람들은 숨을 참고 굳었다가, AI가 숫자를 되찾으면 쓰러졌던 사람들이 깨어난다 → 0은 "잠깐 빌리는 힘".
- `[제안]` 해킹 창이 열려 있어도 게임은 멈추지 않는다. 적이 계속 다가온다.
- `[보류]` 역해킹 중계기를 부수면 유지 시간 연장 — 시간이 남으면

## 7. 게임 루프

1. `[제안]` 구역에 들어가면 전광판이 방송 숫자를 띄운다 → 적 전체 규칙이 정해진다.
2. `[제안]` 적 머리 위 숫자를 읽고 공격 횟수·종류를 예측해 피한다.
3. `[제안]` 숫자가 0이 된 빈틈에 반격하거나, 대시로 돌파한다.
4. `[확정]` (중반 이후) 전광판을 해킹해 방송 숫자를 직접 바꿔 유리하게 만든다. AI가 역해킹해 되찾기 전까지만 유지된다. 0은 강력하지만 사람들이 쓰러진다.
5. `[제안]` 구역 끝 → 짧은 스토리 비트 → 다음 구역.

- [ ] 시민 적은 쓰러뜨리면 기절만 한다. 피·죽음 표현 없음.
- [ ] 맹신 묘사는 가상 기업(Embector) 풍자. 실존 종교 연상 상징 없음 (기도 자세, 성직자 복장 등).
- [ ] 한복·조선 요소는 멋진 패션으로 존중해서 표현. 희화화하지 않음.
- [ ] Embector는 주사기·바늘 이미지로 표현하지 않음. 칩은 "박는다" 정도로만, 주사 연출 없음 (실존 회사 embecta 연상 방지).
- [ ] Embector 로고는 embecta 로고(소문자, 파랑·보라 계열)와 색·모양이 비슷하지 않게.
- [ ] 문화별 숫자 미신을 희화화하지 않음.
- [ ] 술·담배·도박 표현 없음.
- [ ] 실존 인물 이름(Ned Ludd 등)은 역사적 상징으로만 쓰고 실존 인물을 비하하지 않음.
