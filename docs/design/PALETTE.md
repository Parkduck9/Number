# 게임 팔레트 (DRAFT — 사용자 승인 대기)

> 2026-11-08 결정 사항(DECISIONS.md 검수 Top 5 #4): 팔레트 파일 1장(약 24색)을 고정하고 모든 스프라이트·이펙트를 그 팔레트로 맞춘다. 숫자 색 황금·빨강·시안은 가장 밝게.
> 이 문서는 **초안**이다. 승인 전까지 실제 에셋에 양자화 도구를 돌리지 않는다.

## 파일
- 팔레트: `Assets/Art/Palette/number_palette.png` — 24×1 px, 1 px = 1 색 (아래 표 순서). Point 필터·무압축(`PaletteTextureImporter`).
- 스와치(16배): `Assets/Art/Palette/number_palette_swatch16x.png`
- 양자화 미리보기(위 = 원본, 아래 = 양자화, 4배, 배경 #0b1026): `Assets/Art/Palette/previews/`
  - `hero_walk_3f_quant4x.png` (12색 사용), `citizen_attack_3f_quant4x.png` (13색), `sword-slash_quant4x.png` (12색)
- 도구: `Assets/Editor/PaletteQuantizer.cs` → 메뉴 **NUMBER / Quantize Selected To Palette** (Project 창에서 PNG 선택 → 제자리 덮어쓰기, git으로 되돌림)

## 만든 방법
컨셉 이미지(`docs/design/concept/11_character_lineup.jpg`, `15_idle_grid.jpg`, `14_bg_stg01_pixel_native.png` — Codex AI 생성), 현재 DRAFT 스프라이트(`Assets/Resources/DraftSprites/`), pixelfx 이펙트 시트(`Assets/Resources/FX/`)의 픽셀을 OKLab 공간에서 k-means(소스 묶음별 k=8~14)로 뭉친 뒤, 그 중심값을 램프(단계 음영) 단위로 손질해 24색으로 추렸다. 숫자 3색은 컨셉의 숫자 색(빨강 #f00212, 황금 #f2af12)과 FX 시안(#65faf3)을 기준으로 잡고, 중립색(흰색·피부 밝은색)의 밝기를 황금보다 낮게 잘랐다.

## 규칙
1. **숫자 3색(#15 시안, #17 빨강, #19 황금)은 예약색이다.** 숫자 홀로그램(ART-06), HUD 숫자, 숫자에 반응하는 이펙트(파링 섬광·마지막 일격 불꽃·검기)에만 쓴다. 캐릭터·배경·UI 장식에는 쓰지 않는다. 같은 계열이 필요하면 흐린 쪽(#14, #16, #18)을 쓴다.
2. **숫자보다 밝거나 화려한 것을 만들지 않는다.** 흰색은 #9(#d6d7d0)가 상한이다. 순백 `#ffffff`는 팔레트에 없다.
3. 캐릭터 하나는 16색 이하(ANTI_SLOP 2절). 외곽선은 #0 한 가지. 광원은 왼쪽 위 하나.
4. 배경은 N 램프(#1~#5)를 바탕으로 W·A 램프를 포인트로만 얹는다. 네온 보라(#22)는 화면당 전광판·간판 한두 곳.
5. 알파는 0 또는 255. 반투명(글로우·잔상)은 이펙트에서만 의도적으로 쓰고, 그 경우 양자화 도구를 돌리지 않는다.
6. 새 색이 필요하면 이 문서에 먼저 제안하고 승인 후 `number_palette.png` 끝에 덧붙인다(기존 인덱스는 바꾸지 않는다).

## 양자화 도구 사용법
1. 팔레트가 승인된 뒤에만 쓴다. 원본은 git에 있어야 한다.
2. Project 창에서 PNG(들)를 선택 → `NUMBER / Quantize Selected To Palette` → 확인.
3. 알고리즘: alpha < 128 → 완전 투명(0,0,0,0), 그 외 → alpha 255 + OKLab 유클리드 거리로 가장 가까운 팔레트 색. 미리보기 스크립트(Python)와 같은 식·같은 상수를 쓴다.
4. 결과를 원본 크기와 4배 확대로 보고, 실제 씬(960×540) 위에서 확인한다(ANTI_SLOP 5절).

## 미리보기에서 확인된 점 (`[미정]` — 사용자 판단 필요)
- **DRAFT 스프라이트 2종**은 실루엣·음영 변화 없이 12~13색으로 들어온다. 시안 고름은 #14, 피부는 S 램프, 흰 옷은 #8/#9로 매핑된다.
- **sword-slash**: 가장자리의 부드러운 글로우(alpha < 128)가 사라지고, 흰 중심선이 #9(회백색)로 바뀐다. 순백이 필요하면 `#ffffff`를 25번째 색으로 넣어야 하는데, 그러면 "숫자가 가장 밝다" 규칙이 깨진다. 선택지: (a) 그대로 두고 검기 중심을 #15 시안으로 다시 칠함, (b) 이펙트 시트는 양자화에서 제외, (c) 순백 추가.
- 네온 보라(#22)·단청 녹색(#23)은 배경 컨셉(14번)에서만 나왔다. 배경을 새로 그릴 때 안 쓰면 빼서 다른 색(예: 피부/금속 단계)에 자리를 줄 수 있다.
