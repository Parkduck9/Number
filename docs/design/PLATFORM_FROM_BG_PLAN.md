# 배경 그림을 발판으로 쓰기 — 계획 (검토용, 구현 전)

> 작성 2026-11-11 (Claude Opus, 읽기 전용 계획). 코드·씬 변경 없음.
> 사용자 아이디어: 새 발판 그림 대신, 배경에 이미 그려진 지붕·차양·노점 지붕·담·철로·상자 위에 콜라이더를 두고 회색 막대·검은 블록(임시 사각형)을 없앤다.
> 그림 예시: [PLATFORM_FROM_BG_example.png](PLATFORM_FROM_BG_example.png) (STG-02 SEG-A, 초록 = 그림 위 콜라이더 후보, 빨간 X = 없앨 임시 막대, 주황 점선 = 뒤에 그림이 없는 높은 층)

## 0. 결론 먼저

- **낮은 층(바닥 ~ y 8)은 된다.** 월드 고정 그림(소품)과, 건물 줄을 월드 고정으로 바꾸면 그 지붕까지 쓸 수 있다.
- **높은 층(y 9 ~ 23: 탑·지붕길·꼭대기 길·지그재그 통로)은 뒤에 그림이 아예 없다.** 지금 그려진 것 중 가장 높은 지붕은 STG-01 약 9.6, STG-02 약 8.25, STG-04 약 7.75. 세로 맵(DECISIONS 15)의 위쪽 절반은 이 방법만으로는 안 되고 **사용자 결정이 필요하다** (3장).
- 용어 주의: 코드(`Parallax.factor`)에서 **0 = 월드 고정, 1 = 화면 고정**이다. 소품 그룹은 Parallax가 아예 없어 월드 고정.

## 4. 높은 층 ([X]) — 사용자 결정 필요

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **H1 낮추기** | 세로 맵 꼭대기를 그려진 최고 지붕(약 7.75~9.6)까지로 낮춤. 구간 높이 1.5화면 → 약 1.1화면 | 임시 블록이 전부 사라짐, 새 그림 0 | DECISIONS 15 "위로 올라가는 맵" 느낌이 약해짐. 저격수·스폰 장치·체크포인트 다시 배치 |
| **H2 건물 쌓기** | 상가·집 부품을 월드 고정으로 위로 쌓아 탑을 만듦 (예: 집 6.3u + 상가 7.4u ≈ 13.7u → TOWER-A1 13~14.25와 비슷) | 높이 유지, 새 그림 0 | 쌓인 한옥이 어색할 수 있음(슬롭 위험) → **시안 먼저**. 지그재그 통로 발판은 여전히 그림 없음 |
| **H3 위쪽만 유지** | 낮은 층만 그림 발판, 높은 층은 지금 블록 유지 | 가장 빠름, 경로 그대로 | 사용자가 싫어한 검은 블록·회색 막대가 위쪽에 남음 |
| H4 공중 발판에 기존 부품 | 지그재그 발판을 컨베이어(STG-04)·철로 조각(STG-02)으로 그림 | 회색 막대 대신 그림 | 그래도 공중에 떠 있음 |

추천: **1단계로 낮은 층만 바꾸고(H3) 한 스테이지에서 확인 → H1 또는 H2를 사용자가 고름.** H2는 그림 시안 1장(쌓은 탑 1개)을 먼저 보여 준다.

## 5. 건물 줄을 월드 고정으로 바꾸는 것

- **가능하다.** 코드 변경은 작다: `PartsBackdropKit.Buildings()`·`Rail()`의 `Layer(..., BldX, FyBld, ...)`를 Parallax 없는 그룹(`Props()`와 같은 방식)으로, STG-01은 `StreetBackdropKit`의 `MidF`를 (0, 0)으로. `Range()`가 factor 0에서도 구간 전체를 덮는다 (min = 카메라 최소 −16, max = 최대 +16).
- **빌더가 부품을 놓을 때 콜라이더도 같이 만든다:** 부품별 윗면 표(1장 표)를 두고, `Put`/`Row`가 놓은 위치에서 단방향 발판을 만든다 → 그림과 콜라이더가 어긋날 수 없다. 건물 순서는 지금처럼 자동 반복이 아니라 **오르막에 맞게 (부품, x) 목록으로 직접 배치**.
- **잃는 것:**
  - 건물과 거리 사이 깊이감 (하늘·스카이라인·공장 벽은 계속 움직이므로 전체 깊이는 남음).
  - 세로 시차 0.5가 없어져, 높이 올라가면 화면 아래로 건물이 빠짐 → 위쪽 화면이 더 비어 보인다 (H2·H1과 함께 결정).
  - 건물이 0.8로 어둡게 칠해져 있다 → 밟는 지붕이면 소품(0.9)만큼 밝혀야 읽힌다.
  - 담(wall_tile)은 건물 **뒤**에 그려진다. 담 윗면 콜라이더를 건물 앞까지 이으면 플레이어가 건물 벽 중간에 서 있는 것처럼 보인다 → 담 콜라이더는 건물 사이 틈에만.
  - 경사 기와 지붕은 용마루(평평한 줄)만 콜라이더로 — 폭이 1.7~3.9u로 짧다. 근접 적 묶음은 담(긴 길)이나 거리에 두고, 지붕에는 1명씩.

## 6. 위험

1. **경로 끊김 (DECISIONS 15):** 지금 세로 맵은 1.5u 계단으로 짜여 있다. 그림 높이는 1.0~2.0u로 들쭉날쭉 → 스테이지마다 바닥 → 꼭대기 경로를 표로 다시 확인 (모든 단 ≤ 1.5, 2.0은 한 곳까지).
2. **적 배치:** 원거리·저격수는 "플레이어와 같은 높이의 길"이 필요. 짧은 지붕에 원거리를 두면 탄이 아래로 다 지나감. 재배치하면 `Foes` 표와 스폰 장치 `watched` 목록(특히 STG-04의 y ≥ 11.5 조건)을 같이 고쳐야 한다.
3. **D2 지붕 끝 규칙:** 지붕이 짧아지면 적이 금방 떨어진다 — 의도대로인지 플레이로 확인.
4. **체크포인트·문·목표 트리거** (CP-A1/A2/B1, TR-A-DOOR, GATE, GOAL)가 높은 층에 있다 → H1이면 모두 옮김.
5. **갈고리 줄 의존:** 그림 사이 간격이 커서 갈고리 없이는 못 가는 곳이 생기기 쉽다. 갈고리 없이도 갈 수 있게.
6. **캡처와 계산 위치 차이** (2장 참고) — 붙이기 전에 MCP나 캡처로 확인.
7. STG-01 SEG-B는 그림 판 결정 없이는 변화 없음.

### Play 모드 확인 항목 (각 스테이지)
- 바닥에서 꼭대기(또는 낮춘 꼭대기)까지 갈고리 없이 점프만으로 간다.
- 서 있는 발이 그려진 지붕선·상자 뚜껑과 픽셀 단위로 맞고, 카메라가 움직여도 어긋나지 않는다.
- 회색 막대·검은 블록이 낮은 층에 하나도 안 보인다.
- 모든 적·스폰 장치에 닿을 수 있고, 원거리 탄이 플레이어 높이로 날아온다.
