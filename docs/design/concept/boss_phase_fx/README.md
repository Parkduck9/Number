# 보스 페이즈 전환 이펙트 시안 (pixelfx)

지금 `BossFight.PhaseShift`는 흰 섬광, kill-burst, 흔들림, 금만 보여 준다. 그보다 더 무섭고 전환인 줄 바로 알 수 있는 시안 3개다.
모두 pixelfx(MIT)로 새로 만들었다. 팔레트는 빨강(#F0141E와 짙은 빨강 단계)에 시안 #4FF0FF 포인트, 남색 배경 기준이고 24 fps, 한 번 재생, 끝 프레임은 비어 있다.
아직 시안이라서 게임 코드와 `Assets/`는 건드리지 않았다.

## 각 시안
- **A 오버라이드 파열:** 코어가 빛을 빨아들인다(빨강·시안 줄무늬가 안으로 몰리고 어두운 고리가 줄어든다, 0–0.42 s). 이어서 흰 섬광 1프레임과 화면을 가로지르는 흰 선, 두 프레임 동안 빨간 주사선 덮개가 깔린다. 그다음 진홍 충격파와 한 박자 늦은 시안 잔상 고리가 퍼지고, 가로 글리치 띠가 화면을 찢으며 데이터 칸이 흩어진다. "시스템이 덮어써진다"는 느낌이다.
- **B 진홍 왕관:** 시안 전기가 코어 둘레를 기어 다니며 충전된다(0–0.36 s). 흰 섬광 뒤 코어에서 빨간 빛기둥이 천장까지 솟고, 위로 부채꼴을 그리는 빨간 번개 7갈래와 아래 2갈래가 3프레임마다 다시 친다. 그 뒤 기둥이 실처럼 가늘어지며 사라진다. 옥좌 위 왕관 실루엣이라서 궁궐 세계관과 가장 잘 맞는다.
- **C 균열:** 흰 섬광 1프레임 뒤 코어 자리에 검은 프레임이 한 번 들어간다. 이어서 유리처럼 금이 방사형으로 뻗고, 금 사이로 빨간 빛이 새며, 시안 반짝임이 금을 따라 달린다. 빨간 고리가 한 번 퍼지고, 가운데 조각들이 떨어져 나가 어두운 구멍이 남는다. 지금 있는 crack1/2 스프라이트와 이어지는 이야기다.

## PhaseShift에서 재생하는 방법 (통합할 때)
1. 고른 `.png`/`.json`을 `Assets/Resources/FX/boss-phase.png/.json`으로 복사한다. 임포트 설정은 Point 필터, 압축 끔, **Non-Power of 2 = None**이다(크기가 바뀌면 SpriteFx가 오류를 낸다). Max Size는 2048로 충분하다.
2. `PhaseShift` 맨 앞에서 기존 `SpriteFx.Play("kill-burst", c, ...)` 대신 `SpriteFx.Play("boss-phase", c, false, 103)`를 재생한다. 위치 `c`는 코어 자리다.
   - A와 C는 0.42 s / 0.1 s에 터진다. 흰 플래시(`Overlay.Flash`)와 `Juice.Shake`를 그 시점으로 늦추면 맞는다. B는 0.36 s다.
   - 금 스프라이트(`crack1/2`) 켜기는 지금처럼 0.35 s 대기 뒤에 둔다. C를 고르면 이펙트가 끝나는 1.1 s 무렵 켜는 편이 자연스럽다.
3. 크기는 1x(PPU 32) 기준이다. A ≈ 12×7 유닛, B ≈ 9×8 유닛(기둥이 코어 위 5.5 유닛까지), C ≈ 10×7.5 유닛이다. 화면 전체(30 유닛) 글리치가 필요하면 A의 띠는 그대로 두고, `Overlay`에 코드로 된 전체 화면 빨간 깜빡임을 더하는 쪽이 시트를 키우는 것보다 싸다.
4. 넣게 되면 CREDITS.md에 pixelfx(MIT, Patch / Hugo Duprez)를 기록한다.
