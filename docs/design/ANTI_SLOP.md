# AI 슬롭 금지 가이드

> 2026-11-08 사용자 지시. 그림·UI·캐릭터·이펙트처럼 **화면에 보이는 모든 것**에 적용한다. 모든 AI(Claude·Codex·Antigravity)가 지킨다.
> "AI 슬롭" = AI가 통계적으로 흔한 결과를 내서 생기는, 누가 봐도 AI가 만든 티가 나는 뻔하고 어설픈 결과물.

## 1. 진행 순서 (보이는 것을 만들 때 항상)

1. **먼저 말로 설명한다.** 무엇을, 어떤 크기·팔레트·구도·참고 이미지로, 어떤 도구(Codex 등)로 만들지 사용자에게 말한다.
2. **가능하면 예시를 먼저 뽑는다.** 시안 1~2장(작게, 한 동작·한 화면)을 만들어 사용자에게 보여 준다.
3. **사용자가 확인한 뒤에** 본 작업(전체 프레임·전체 세트)을 한다.
4. 결과물을 넣기 전에 아래 2~4절 체크리스트로 직접 확인한다. 걸리면 고치고 다시 보여 준다.

## 2. 픽셀 아트 (스프라이트·배경·이펙트)

| 슬롭 징후 | 우리 규칙 |
|---|---|
| 픽셀 크기가 들쭉날쭉, 모서리가 뭉개짐, 선이 1.5픽셀처럼 번짐 | 모든 에셋은 한 격자(PPU 16, 480×270 기준)에 맞춘다. 정수 배율·Point 필터만 |
| 가장자리에 흐릿한 후광(안티앨리어싱·반투명 테두리) | 외곽선 알파는 0 또는 255. 반투명 픽셀은 이펙트에만 의도해서 |
| 크기에 비해 디테일이 너무 많음, 초점이 없음 | 28~34px 캐릭터는 실루엣으로 읽혀야 한다. 디테일보다 형태·색 덩어리 |
| 색이 수십~수백 개, 부드러운 그라데이션 | 에셋마다 제한된 팔레트(캐릭터 16색 이하 권장). 그라데이션 대신 단계 음영(디더링은 의도적으로만) |
| 빛 방향이 에셋마다 다름 | 광원 방향을 하나로 정하고 모든 에셋이 따른다 |
| 그림 속 글자가 뭉개진 가짜 문자 (가짜 한글·한자·영어) | 그림 안에 글자를 AI로 그리지 않는다. 간판·숫자는 폰트나 손으로 찍은 픽셀로 따로 올린다 |
| 프레임마다 캐릭터 비율·옷·색이 바뀜 | 기준 대기 자세 한 장을 정하고 모든 동작 프레임을 그 위에서 만든다. 프레임끼리 겹쳐 비교한다 |

## 3. 캐릭터·세계관 디자인

- **뻔한 사이버펑크 금지:** 네온 핑크+시안 범벅, 일본·중국풍 네온 거리, 빛나는 눈, 의미 없는 홀로그램 문자, 카타나. 우리 세계는 **조선**이다 — 한옥 처마 곡선·기와·단청·한복 실루엣이 먼저 읽혀야 한다 (GDD ART-02·03).
- 중국식 누각·일본식 지붕·기모노 같은 다른 문화 요소가 섞이지 않게 한다.
- **얼굴·손·비율:** 눈동자 짝이 안 맞음, 손가락 수 오류, 좌우 대칭 마네킹 얼굴. 작아도 확인한다.
- **개성:** 매끈하고 무표정한 "평균 얼굴"보다 실루엣·자세·소품 하나로 기억나는 캐릭터. 모든 캐릭터가 같은 체형·같은 포즈면 실패.
- 숫자 홀로그램은 **얼굴 앞**, 가장 밝은 요소 (ART-06). 다른 요소가 숫자보다 밝거나 화려하면 안 된다.

## 4. UI / UX

| 슬롭 징후 | 우리 규칙 |
|---|---|
| 보라→파랑 그라데이션, 글자 그라데이션 | 게임 팔레트(남색·검정 + 숫자의 황금/빨강/시안)만 쓴다 |
| 이모지·범용 아이콘(✨🚀⚡)을 장식으로 | 이모지 금지. 아이콘은 게임 픽셀 아트로 직접 |
| 기본 폰트(Inter·Roboto·Arial·DM Sans·Space Grotesk), 부드러운 벡터 폰트 | 픽셀 폰트(무료 라이선스, CREDITS.md 기록). 한글도 픽셀 폰트 |
| 둥근 모서리 카드·글래스모피즘·그림자 남발, 똑같은 카드 반복 | 각진 픽셀 프레임. 화면마다 필요한 정보만 |
| 의미 없는 장식 애니메이션, 흔한 "시스템 부팅" 연출 | 움직임은 정보(숫자 변화·피격·예고)를 전할 때만 |
| 문구가 마케팅체·과장 ("Unleash your destiny!") | 짧고 건조하게. 세계관 말투(방송·경고문)로 |

## 5. 확인 방법

- 원본 크기와 4배 확대 둘 다로 본다.
- 실제 게임 화면(480×270, 배경 위)에 놓고 본다 — 따로 볼 때 괜찮아도 같이 놓으면 튄다.
- "이게 AI가 만든 것처럼 보이나?"를 위 표 기준으로 하나씩 대답한다. 하나라도 걸리면 고친다.
