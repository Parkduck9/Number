# 튜토리얼 영상 촬영 목록

튜토리얼 카드(`Stg01Tutorial`) 위쪽 영상 슬롯에 반복 재생되는 짧은 클립. 파일이 없으면 슬롯이 사라지고 카드가 줄어들 뿐이라 게임은 영상 없이도 동작한다.

## 규격
- 형식: **MP4 (H.264, 오디오 없음)**. WebGL 브라우저 호환 때문에 H.264 baseline/main, yuv420p.
- 해상도 **480x270 (16:9)**, 15~30fps, 길이 **3~5초**, 루프로 자연스럽게 이어지게 (시작과 끝 동작이 같은 자리).
- 용량은 클립당 **1MB 이하** 목표 (WebGL 용량).
- 화면은 실제 게임 화면 녹화. 마우스 커서(조준점)가 보이게, 불필요한 HUD는 최소화.
- 저장 위치: `Assets/StreamingAssets/Tutorial/<이름>.mp4`

## 클립 목록
| 파일 | 스텝 | 보여줄 것 |
|---|---|---|
| `1_move.mp4` (선택) | 1 이동 | A/D로 걸어가 Space로 상자를 넘는다. 키 입력이 화면 구석에 보이면 좋다. |
| `2_strike.mp4` | 2 베기 | 경비 로봇 앞에서 마우스를 로봇 쪽에 두고 좌클릭, 돌진 베기로 쓰러뜨린다. 돌진 방향이 마우스 쪽임이 보이게. |
| `3_issen.mp4` | 3 일섬 | 같은 높이의 막는 적 앞에서 Shift, 번개처럼 꿰뚫고 지나가 적이 쓰러진다. 일반 베기는 막히는 장면을 먼저 1초 정도 넣어도 좋다. |
| `4_parry.mp4` | 4 패링 | 안드로이드 얼굴 앞 숫자와 두 고리가 줄어들다 겹치는 순간 좌클릭, 패링 성공, 과부하로 멈추면 베어 쓰러뜨린다. 고리가 겹치는 순간이 크게 보이게. |
| `5_rope.mp4` | 5 밧줄 | 벽 앞(점프로 못 오르는 높이)에서 지붕 끝 근처 우클릭, 밧줄이 걸려 끌어올려지는 장면. |
| `6_dice.mp4` | 6 행운의 주사위 | E로 주사위를 굴려 눈이 나오고 스킬이 발동해 적이 쓰러지는 장면 (눈 하나만 보여 줘도 된다). |

클립 이름은 `Assets/Data/Dialogue/stg01_tutorial.txt`의 `#clip <이름>`과 일치해야 한다. 새 클립을 붙이려면 해당 스텝에 `#clip <이름>` 한 줄만 넣으면 된다.
