# 플레이테스트 가이드 (Title → 엔딩, 약 20분)

처음으로 끝까지 해 보는 날이다. 막히면 멈추고 메모만 남겨라. 고치는 건 나중이다.

> 주의: 효과음·BGM, 얼굴 체력 HUD, 방송 숫자 창 새 그림, STG-02~05 배경 시안은 아직 **main에 없다** (별도 브랜치, 승인 대기). 지금 main에서는 소리가 안 나고 HUD·배경이 임시 모양일 수 있다. 그건 버그가 아니다. 소리·HUD 줄은 병합 뒤에 확인한다.

## 0. 준비
1. 최신 코드를 받는다 (Fetch/Pull).
2. Unity에서 `Assets/Scenes/Title.unity`를 연다.
3. 컴파일이 끝나면 메뉴를 **이 순서로** 실행해 씬을 다시 만든다.
   - `NUMBER/Build Title Scene`
   - `NUMBER/Build STG-01`
   - `NUMBER/Build All Stages (00,02,03,04)`
   - `NUMBER/Build STG-05`
   - `NUMBER/Sync Build Settings (stage order)` (씬 순서)
4. 콘솔에 빨간 오류가 없는지 본다. 있으면 그 글자를 메모에 붙인다.
5. `Title.unity`를 열고 Play. 중간부터 하고 싶으면 `STG0X.unity`를 직접 열어 Play.
6. 배치 실행 뒤 `Mulmaru SDF.asset`, `LiberationSans SDF.asset`이 바뀌어 있으면 되돌린다 (HANDOFF 5장).

조작: A/D 이동, W 점프, 좌클릭 공격, 우클릭 패링, Shift 대시, E 상호작용(전광판·버튼), Space 충격파(STG-03부터), Esc 일시정지, R 재시작.

## 1. 스테이지별 확인 표

### 타이틀
| 이렇게 하면 | 이게 보여야 함 |
|---|---|
| Play 직후 | 금색 `0` 하나와 NUMB-ER 로고 |
| 시작 선택 | STG-00으로 넘어간다 |
| 종료 선택 (에디터) | Play 모드가 꺼진다 |

### STG-00 (오프닝)
| 이렇게 하면 | 이게 보여야 함 |
|---|---|
| 1.5초 기다린다 | 전광판이 **0**으로 바뀌고 라디오 자막이 뜬다. 시민은 계속 걷는다 |
| 농담 대화창을 닫는다 | 0.3초 뒤 화면이 거의 검게 되고 노란 `0`만 밝다 |
| 정전 중 시민을 본다 | 전광판 가까운 시민부터 한 명씩 회색으로 굳는다 |
| 컷 1초 뒤 오른쪽으로 달린다 | 출구로 나갈 수 있다. 몇 초 뒤 밝아진다 |
| 정전 중 Esc, 해제 | 타이머가 멈췄다가 이어진다 |
| 걸어 다닌다 | 주인공 걷기 임시 스프라이트가 보인다 |

### STG-01
| 이렇게 하면 | 이게 보여야 함 |
|---|---|
| 시작해서 첫 원거리 적을 본다 | 탄이 나에게 닿는다. 피하거나 막을 수 있다 |
| 적 2.5유닛 앞에서 좌클릭 | 미끄러져 붙어서 바로 때린다 (자동 접근) |
| 적 3.5유닛 앞에서 좌클릭 | 제자리 헛스윙. 등 뒤의 적도 제자리 |
| 일반 적을 한 번 때린다 | 한 방에 쓰러지고 0.5초 뒤 사라진다 |
| 적 1.5유닛 앞에서 Shift | 적의 바로 뒤로 이동한다. 적이 없으면 정해진 거리만 이동 |
| 대문을 지난다 | 방송 `((( 3 )))`이 커졌다 작아지며 뜬다. 방송 HUD만 있고 해킹 다이얼은 없다 (STG-01·02) |

### STG-02
| 이렇게 하면 | 이게 보여야 함 |
|---|---|
| 들어온다 | 배경이 STG-01과 구별된다 (시안 병합 전이면 임시) |
| 벌레 적을 본다 | 1픽셀 점 떼 모양이다. 때리면 한 방에 쓰러진다 |
| 연타하는 적을 본다 | 적 숫자만큼 연속으로 공격한다. 연타 뒤 반격 창이 열린다 |
| 벽·낭떠러지 건너의 적에게 좌클릭 | 접근이 안 되고 제자리 공격. 떨어지지 않는다 |
| 방송 숫자를 본다 | 상단 HUD에 3 또는 7 또는 0이 나온다 |
| 적탄이 날아올 때 Shift | 무적으로 통과해 탄을 피한다 |

### STG-03 (해킹 다이얼·충격파 시작)
| 이렇게 하면 | 이게 보여야 함 |
|---|---|
| 전광판 앞에서 E | 숫자 다이얼이 열린다. 0~9 키, 위아래·휠로 바뀐다 |
| 0으로 해킹 | 시민이 푸른 회색으로 굳는다. 진행 바가 찬다. 5초 뒤 풀린다 |
| 7로 해킹 | 적이 빨라진다. 8초 안에 7초가 지나면 적이 2초간 열려서 맞는다 |
| Space | 앞쪽 적이 1초 굳는다. 쿨다운 5초 (왼쪽 아래 글자) |
| 안드로이드 마지막 일격을 우클릭 패링 | 몸이 깜빡이고 `ERR` 라벨. 1.5초 과부하 |
| 과부하 중 한 대 | 쓰러지고 0.5초 뒤 사라진다. 그 밖에서 때리면 흰색 번쩍만 |

### STG-04
| 이렇게 하면 | 이게 보여야 함 |
|---|---|
| 들어온다 | 배경이 달라진다. 적이 묶음·원거리·발판으로 섞여 있다 |
| 숫자 7 안드로이드의 7번째 일격을 Shift로 통과 | 과부하가 된다. 패링 시도는 맞는다 |
| 안드로이드에게 좌클릭 접근 | 붙지만 흰색으로 막힌다 |
| 죽는다 | 체크포인트에서 다시 시작. 충격파는 그대로 쓸 수 있다 |
| 해킹 중 멀어진다 | 다이얼이 닫힌다 |
| 대시로 적 뒤에서 벽·낭떠러지 | 정해진 거리 대시로 바뀐다. 떨어지지 않는다 |

### STG-05 (보스)
| 이렇게 하면 | 이게 보여야 함 |
|---|---|
| 오른쪽으로 걸어간다 | "WAVE 1 - LUCKY 3", 방송 3, 시민 4명이 떨어진다 |
| 모두 기절시킨다 | 1.5초 뒤 "WAVE 2 - LUCKY 7" (시민 3 + 금색 원거리 2) |
| 또 모두 기절시킨다 | "WAVE 3 - LUCKY 0" (강한 적 2 + 시민 3). 안드로이드는 얼지 않는다 |
| 웨이브 중 전광판에서 E → 바로 E | "STOP BUTTON UNLOCKED", 오른쪽에 빨간 버튼 |
| 2웨이브에 해킹하고 3웨이브로 넘어간다 | 버튼이 열리지 않는다. 새로 해킹하면 열린다 |
| 싸우다 죽는다 | 씬이 다시 시작되고 1웨이브부터 |

### 엔딩 (정지 버튼)
| 이렇게 하면 | 이게 보여야 함 |
|---|---|
| 버튼 앞에서 E | 1/2 선택창. Esc로 닫힌다 |
| 1 선택 | 엔딩 1 대화 → 타이틀 |
| 2 선택 | 해킹 다이얼과 같은 판, 제목 "LUCKY NUMBER", 시작 숫자 = 방송 숫자 |
| 다이얼에서 숫자 고르고 E | END-02 대화 → 마지막 줄 뒤 타이틀 |
| 다이얼에서 Esc | 선택창으로 돌아간다 (일시정지 메뉴가 뜨면 버그) |

## 2. 빠른 이동 (에디터 전용 키)
- **F9**: 충격파 해금 켜기/끄기. STG-03 이전 씬에서 Space를 시험할 때 쓴다 (콘솔에 `[Shockwave] debug unlock`).
- **L**: 한국어/영어 전환 (에디터·개발 빌드).
- 다른 장면 점프 키는 없다. 원하는 씬 `.unity`를 직접 열어 Play 한다.
- 체력·무적 치트는 없다.
