# BUG-R2-01: 스폰 장치가 적을 원래 자리에 즉시 되살려서, 장치를 때리는 플레이어 바로 옆에 적이 생긴다 (안전 반경 없음)

## 심각도
**중간**

## 재현 단계
1. STG-01 SEG-B 끝(고가 지붕)까지 올라가 스폰 장치(SPAWNER-B, x 66.5)를 때리려 한다. 장치 양옆에 E-B7(x 65)·E-B8(x 68)이 있다.
2. 두 적을 죽이고 장치 쪽으로 붙어 선다 (장치를 때리려면 장치 중심에서 약 2.75u 안에 서야 한다).
3. 2.5초 뒤 E-B7·E-B8이 원래 자리(장치에서 1.5u)에 다시 생긴다.

## 기대 결과
- 장치를 부수는 중에는 부활한 적이 플레이어를 바로 때리지 못한다 (예: 플레이어가 가까우면 부활을 조금 미루거나, 잠깐 무적 예고를 준다).
- 보스전에는 같은 문제를 막으려고 안전 반경(BOSS-03 `spawn-safe-radius`)이 있었다.

## 실제 결과
- 부활한 적이 플레이어 공격 사거리(`attackRangeX` 1.8u) 안에 나타나고, 첫 선공 예고는 `max(0.5 × 0.55, 0.2)` = 약 0.275초뿐이라 바로 맞는다. 플레이어 쪽 "적 겹침 무시"(Player/Enemy 레이어 충돌 끔) 때문에 몸이 겹쳐 생기기도 한다.
- 장치를 2번 때리는 동안(스윙 2번 ≈ 0.6초 이상) 부활 주기 2.5초와 겹치면 반드시 한 번은 이런 상황이 생긴다.

## 근거
- `Assets/Scripts/Level/EnemySpawner.cs:135`: `e.current = Instantiate(e.template, e.pos, e.rot, e.parent);` → 항상 씬 시작 위치(`e.pos`, 76행). 플레이어와의 거리 검사 없음.
- 장치 파괴 가능 거리: `EnemySpawner.cs:24` 스윙 박스 오프셋 0.9 + 크기 2.1 → 플레이어 중심에서 최대 1.95u + 장치 박스 반폭 0.8 = 2.75u.
- 배치 값 (빌더, 세그먼트 로컬 x):
  - STG-01: 장치 66.5 / E-B7 65 (1.5u) / E-B8 68 (1.5u) — `Stg01Builder.cs` Foes·Spawner.
  - STG-02: 장치 35.5 / E-B9 37 (1.5u, 원거리 벌레) — `Stg02Builder.cs`.
  - STG-04: 장치 68 / E-B7 66 (2.0u) / S-B1 저격 70.5 (2.5u).
- 선공 예고: `TestEnemy.cs:580-586` `WindupWait()`, `Juice.NormalTimeMul` 0.55, `Juice.MinFirstWindup` 0.2.

## 제안 (수정은 Sonnet)
- `UpdateRespawns`에서 플레이어가 `e.pos`에서 3u 안이면 부활을 최대 1초 미루거나, 부활 직후 0.5초 동안 `Frozen`처럼 굳게 한다.
