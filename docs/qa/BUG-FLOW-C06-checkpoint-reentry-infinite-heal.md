# BUG-FLOW-C06 — 체크포인트를 나갔다 다시 밟으면 몇 번이든 체력이 가득 찬다 (전투 중 무한 회복)

## 재현 단계
1. STG-02 SEG-B에 도착한다 (도착 지점 = CP-B0, x 2).
2. 오른쪽으로 가서 E-B1(x 20) 근처에서 2~3대 맞는다 (얼굴 HUD가 바뀜).
3. 왼쪽으로 물러나 CP-B0 표식에 다시 닿는다 (한 번 벗어났다가 다시 들어가면 됨).
4. 다시 싸우고, 2~3을 원하는 만큼 반복한다.

## 기대 결과 (기획 확인 필요)
GDD `[확정]` "체크포인트에 닿으면 얼굴이 원래대로 돌아온다(체력 회복)" (`docs/design/GDD.md:143`). 이것이 **처음 닿을 때 한 번**인지 **닿을 때마다**인지는 문서에 없다. 액션 난이도를 생각하면 보통은 "처음 한 번(또는 새 체크포인트를 켤 때)"이다.

## 실제 결과 (코드 근거)
- `Assets/Scripts/Checkpoint/Checkpoint.cs:18-27` `OnTriggerEnter2D`는 들어올 때마다 `RestoreFull()`을 부른다. "이미 켜진 체크포인트" 확인이 없다.
- 체크포인트가 구간 시작에 있고(`Assets/Editor/Stg02Builder.cs:33`, `Stg04Builder.cs:33`, `Stg01Builder.cs:77`: CP-B0 x 2), 첫 적은 x 20~30이라 뒤로 물러나 회복하는 것이 쉽다. 적 감지 범위는 8u(`Stg02Builder.cs:37-43`)라 대부분 따라오지도 않는다.
- 결과: 피격 5번 = 사망 규칙(얼굴 체력)이 사실상 무의미해진다. STG-01·02·04 모든 SEG-B에서 같다.

## 수정 제안 (참고)
- 기획이 "처음 한 번"이면: `Checkpoint`에 `bool used`를 두고 처음 닿을 때만 `RestoreFull()` (기록 갱신은 계속 해도 됨). 씬 다시 로드(리스폰) 때 초기화되므로 리스폰 후 첫 접촉은 그대로 회복된다.
- 기획이 "매번"이 맞으면 이 리포트를 닫는다.
