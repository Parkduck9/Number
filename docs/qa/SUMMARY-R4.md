# QA 4차 요약

범위: `2550b33..25a974e` (확인 당시 HEAD). 제공된 `docs/qa/_qa4_diff.txt` 전체와 DECISIONS 34–40, HANDOFF, 기존 QA 3차·제출 체크리스트를 읽고 관련 호출 경로를 대조했다. Editor 코드는 제공된 커밋 diff를 기준으로 검토했으며 다른 AI의 미커밋 변경은 판정에 사용하지 않았다.

Unity·Play 모드·빌드·브라우저는 실행하지 않았다. 아래 실제 결과는 코드로 확인한 결과이며 실행 관찰을 뜻하지 않는다. 변경된 현존 C# 스크립트 26개는 LF 정규화 후 Git blob SHA-1을 계산하여 제공 diff의 최종 해시와 일치함을 확인했다.

요청한 `git log --oneline 2550b33..HEAD`는 git이 PATH에 없고 GitHub Desktop 내장 경로 접근/실행도 실패해 실행하지 못했다. 커밋 범위는 사용자 제공 목록, `.git/HEAD`·`refs/heads/main`·reflog로 대조했다. git 변경 명령은 실행하지 않았다.

검토 순서: 1. 확정 의도와 변경 대조 → 2. 입력·피해·중단/해제 경로 추적 → 3. 근거가 있는 버그와 실행 점검표 분리.

## Play 모드에서 확인할 것

아래 항목은 전부 **미실행**. Unity **6000.3.28f1**에서 확인 후 최종 WebGL에서도 핵심 경로를 반복한다.

### 입력·이동·상태 복구

- [ ] Space만으로 점프, W+Space도 점프가 빠지지 않는다. A/D 이동과 함께 눌러도 정상이다.
- [ ] 제자리 공격·패링 모션 중 Space로 점프하고 공격 판정/패링 창은 정상 종료된다. 돌진 공격 중·종료 직전의 점프 버퍼도 별도로 확인한다.
- [ ] 같은 높이의 조준 적(중심 높이 차 ≤1u)에게 Shift 일섬, 높이 차 >1u/대상 없음/일섬 쿨타임 중에는 일반 대시가 나온다. 보스 코어는 높이 예외다.
- [ ] 일반 대시 0.15초·약 3.6u·무적·쿨타임 0.6초, 벽에서 정지, 끝에 방향 전환/자동 반격 없음. 일섬 5초 쿨타임과 별개이며 HUD는 일섬만 표시한다.
- [ ] 공격·패링·대시·갈고리 중 Shift/RMB/LMB를 눌러 버퍼의 실행 시점을 확인한다. 히트스톱 중 누른 Space/Shift/RMB/E가 풀린 뒤 한 번만 실행된다.
- [ ] 원웨이에서 S+Space 및 ↓+Space로 내려간다. 단단한 바닥에서는 점프한다. A/D와 함께 눌렀을 때, 겹친 발판·발판 끝·점프 착지 직전 버퍼도 확인한다.
- [ ] 내려간 뒤 같은 발판으로 다시 올라타면 충돌이 복구된다. 내려가는 중 피격·사망·주사위·대화·일시정지 후에도 충돌 무시가 남지 않는다.
- [ ] RMB 천장/고리 당김 → 진자, A/D 가속, Space/RMB 새총(속도 ×1.15 + 위쪽 점프 속도 ×0.35), 0.8초 관성 유지. 벽/원웨이는 기존 끌기·상승 반동이다.
- [ ] 진자에서 S·착지·2.5초 제한은 단순 놓기, LMB는 놓고 공격. 고리에서 RMB로 다른 고리/열린 해치로 재연결하고 빗나가면 자연스럽게 떨어진다.
- [ ] 줄 중 피격·사망·대화·E 스킬·P/Esc·포커스 이탈 → 줄 그림/중력/입력/무적이 정상 상태로 돌아온다. 사망/체크포인트 재시작/타이틀 후 재시작도 반복한다.
- [ ] NUM-7 안드로이드 마지막 일격을 Shift 일섬 또는 일반 대시로 공격 범위 안에서 통과하면 과부하, 단순 범위 밖 회피는 과부하가 아니다. 이후 처치하고 골에 도달할 수 있다.

### 패링·주사위·체크포인트

- [ ] 근접 상/중/하·정예 결투·보스 내려찍기·가로/수직/사선 탄 패링에서 접점이 빛나고, 주인공 흰 번쩍임과 화면 전체 금색 섬광은 없다. 피격 빨강은 남는다.
- [ ] 반지름 15px 고리의 접근 고리·정답 고리가 같은 접점에 합쳐지고, 확대 카메라/30fps/히트스톱에서도 입력 창과 맞는다.
- [ ] 해금 후 일반 LMB·관통 다중 타격·Shift 일섬·보스 코어/칼 연타/쓰러진 벌레팔 적중이 대상당 +1. 6회에는 사용 불가, 7회에는 준비, 8회에도 저장은 1회분이다.
- [ ] 빈 휘두르기·안드로이드 방어·패링·반사탄·주사위 1–6번의 타격은 충전하지 않는다. 5번 부적 연쇄 중 일반 공격도 Busy 규칙대로 처리된다.
- [ ] E 상호작용 근처에서는 상호작용만, 떨어진 곳에서는 주사위만 실행된다. 대화 마지막 E·주사위 끝·히트스톱·정지 해제 직후 중복 사용이 없다.
- [ ] 체크포인트 미점등/점등 그림이 바닥에 붙고, 재진입 시 회복, 사망 후 기록한 위치와 점등 상태 복원, 새 게임에서는 이전 기록이 남지 않는다.
