## 제출 체크리스트 (요약)
- [ ] 팀원 전원 만 19세 이상, 최근 12개월 안에 Unity 상을 받은 적 없음
- [ ] 게임 UI 영어 (가능하면 한국어도 함께)
- [ ] 차별·혐오, 술·담배 홍보 콘텐츠 없음
- [ ] itch.io에 WebGL 빌드 업로드 + "브라우저에서 플레이 가능" 체크
- [ ] 간단한 설명 / 조작법
- [ ] 모든 에셋 크레딧
- [ ] 팀 구성원 정보
- [ ] 생성형 AI 사용 내역 공개 (미공개 시 상 후보 자격 박탈)
- [ ] 마감 후 심사 기간(11/14~)에는 게임 파일 수정 금지

## 다른 PC에서 작업하기
1. GitHub Desktop → File → Clone repository → 이 저장소 선택
2. Unity Hub → Add → 클론한 폴더 선택 (같은 Unity 버전 사용)
3. 작업 전 항상 **Fetch/Pull**, 작업 후 **Commit → Push**
